# Agri Platform

농장주, 도매업자, 토지매매자를 연결하는 Streamlit 기반 농업 플랫폼 프로토타입.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 테스트 계정

- 농장주: farmer@test.com / 1234
- 도매업자: wholesaler@test.com / 1234
- 토지매매자: land@test.com / 1234

> 현재 계정 정보와 데이터 저장 방식은 개발용 프로토타입입니다. 실제 서비스에서는 비밀번호를 평문으로 저장하지 말고 안전한 인증 및 데이터베이스를 사용해야 합니다.
